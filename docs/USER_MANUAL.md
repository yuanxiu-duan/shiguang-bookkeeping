## 1. 产品简介

拾光账本是一款简洁实用的多端记账应用，支持 iOS、Android、H5、微信小程序和 Web 端，帮助您：

- 随手记录日常收支
- 与家人共享账本，协同记账
- 设置预算，控制开支
- 查看统计分析，掌握财务状况
- 导出账单数据，备份留存

---

## 2. 快速开始

### 2.1 注册账号

1. 打开 App / 访问 Web 端
2. 点击"注册"按钮
3. 填写信息：
   - 用户名（3-50 位字符，唯一）
   - 密码（6 位以上）
   - 邮箱（用于找回密码和接收导出文件）
   - 邮箱验证码（点击"发送验证码"获取）
4. 点击"注册"按钮
5. 注册成功后自动登录

> 注册后会自动创建一个名为"默认账本"的账本和 13 个常用分类。

### 2.2 登录

**密码登录**：
1. 输入用户名和密码
2. 点击"登录"

**验证码登录**：
1. 切换到"验证码登录"模式
2. 输入邮箱
3. 点击"发送验证码"
4. 输入收到的 6 位验证码
5. 点击"登录"

### 2.3 记第一笔账

1. 在首页点击右下角"+"按钮
2. 选择类型：支出 / 收入
3. 选择分类（如：餐饮）
4. 输入金额
5. 可选：填写备注、选择标签、修改日期
6. 点击"保存"
7. 返回首页即可看到新记录

## 3. 功能详解

### 3.1 记账首页

**功能**：
- 顶部显示当月收入、支出、结余
- 中部显示近期交易列表
- 底部 TabBar 切换：账单 / 统计 / 我的

**操作**：
- 点击"+"按钮：记一笔
- 点击列表项：编辑交易
- 左滑/长按列表项：删除交易
- 下拉刷新：获取最新数据

### 3.2 记一笔

**字段说明**：
| 字段 | 说明 | 必填 |
|------|------|------|
| 类型 | 支出 / 收入 | 是 |
| 分类 | 选择对应分类 | 是 |
| 金额 | 输入金额（支持小数） | 是 |
| 日期 | 默认今天 | 是 |
| 账本 | 默认当前账本 | 是 |
| 备注 | 自由文本 | 否 |
| 标签 | 可多选 | 否 |

**智能分类**：
- 输入备注后，点击"智能分类"按钮
- 系统根据关键词自动推荐分类
- 例如：备注"星巴克"→ 推荐分类"餐饮"

### 3.3 统计分析

**月统计**：
- 显示当月总收入、总支出、结余
- 分类占比饼图
- 收支对比柱状图

**年统计**：
- 12 个月收支趋势
- 年度分类汇总

**趋势**：
- 近 12 个月收支趋势曲线
- 单个分类的趋势变化

### 3.4 账本管理

#### 3.4.1 创建账本
1. 进入"我的"→"账本管理"
2. 点击"新建账本"
3. 输入名称和描述
4. 保存

#### 3.4.2 共享账本（邀请家人）
1. 进入账本详情
2. 点击"邀请成员"
3. 输入对方的用户名
4. 对方收到邀请后，在"账本管理"→"待处理邀请"中接受

**成员角色**：
- 所有者（OWNER）：账本全部权限，可邀请/移除成员
- 成员（MEMBER）：可在账本内记账，仅能编辑/删除自己的记录

#### 3.4.3 设置别名
- 在账本内可设置自己的别名
- 别名仅本人可见，方便区分

### 3.5 预算管理

#### 3.5.1 创建预算
1. 进入"预算管理"页面
2. 点击"新建预算"
3. 选择分类、月份、金额
4. 设置告警阈值（默认 80%）
5. 保存

**示例**：
- 餐饮预算 2000 元，阈值 80%
- 当支出达到 1600 元时，生成预警

#### 3.5.2 预算预警
- 当支出达到阈值时，自动生成预警
- "我的"页面显示未读预警红点
- 进入预警页面查看详情
- 可标记单条已读或全部已读

### 3.6 分类管理

**默认分类**：
- 支出：餐饮、交通、日用品、娱乐、居住、医疗、教育、其他支出
- 收入：工资、奖金、投资、兼职、其他收入

**自定义分类**：
1. 进入"分类管理"
2. 点击"新建分类"
3. 输入名称、选择类型、选择图标
4. 保存

### 3.7 标签管理

**用途**：为交易添加辅助标记，如"工作日"、"旅行"、"报销"

**操作**：
1. 进入"标签管理"
2. 创建标签（名称 + 颜色）
3. 记账时选择标签（可多选）
4. 查询交易时可按标签筛选

### 3.8 数据导出

#### 3.8.1 异步导出（推荐）
1. 进入"导出数据"页面
2. 选择时间范围
3. 确认接收邮箱
4. 提交导出任务
5. 等待邮件通知（通常几分钟内）
6. 邮件附件为 Excel 文件（大文件自动压缩 zip）

#### 3.8.2 查看任务状态
- 在"导出数据"页面查看最近任务
- 状态：待处理 → 处理中 → 成功/失败

### 3.9 账号设置

进入"我的"→"账号设置"：

| 功能 | 说明 |
|------|------|
| 修改昵称 | 显示在个人主页 |
| 修改邮箱 | 需验证旧邮箱 + 新邮箱 |
| 修改密码 | 需输入旧密码 |

### 3.10 找回密码

1. 登录页点击"忘记密码"
2. 输入注册邮箱
3. 获取验证码
4. 输入新密码（两次一致）
5. 重置成功后用新密码登录

## 4. Web 管理端使用

### 4.1 访问地址
浏览器访问 Web 端地址（如 `https://your-domain.com`）

### 4.2 主要功能

| 菜单 | 功能 |
|------|------|
| 账单流水 | 查看全部交易、筛选、导入导出 |
| 记账 | 录入交易 |
| 报表 | 统计报表可视化 |
| 预算管理 | 预算 CRUD |
| 分类管理 | 分类 CRUD |
| 账本管理 | 账本 + 成员管理 |
| 后台管理 | OSS 配置 + APP 发布（仅 ADMIN） |

### 4.3 后台管理（仅管理员）

#### 4.3.1 OSS 配置
- 添加对象存储配置（阿里云/腾讯云/七牛/MinIO/AWS）
- 测试连接
- 激活一个配置作为当前使用

#### 4.3.2 APP 发布
1. 上传 APK 文件到 OSS
2. 创建发布记录（版本号、更新说明、是否强制更新）
3. 点击"发布"按钮
4. App 端会自动检测到新版本并提示用户升级

## 5. APP 升级

### 5.1 自动检测
- App 启动后 3 秒自动检查更新
- 有新版本时弹出升级提示

### 5.2 手动检查
- 进入"我的"→"检查更新"

### 5.3 升级流程
- **可选更新**：可点击"取消"跳过
- **强制更新**：必须升级才能继续使用
- **Android**：下载 APK → 显示进度 → 自动调用系统安装器
- **iOS**：跳转浏览器下载链接

## 6. 常见问题

### Q1：忘记密码怎么办？
A：登录页点击"忘记密码"，通过注册邮箱重置。

### Q2：可以多人共用一个账本吗？
A：可以。账本所有者邀请其他用户加入，成员可在该账本内记账。

### Q3：别人能修改我的交易记录吗？
A：不能。只有交易创建者和账本所有者可以编辑/删除交易。

### Q4：导出的 Excel 包含哪些字段？
A：日期、类型、分类、金额、备注、创建人。

### Q5：导出任务多久能完成？
A：通常几分钟内。系统每 60 秒处理一个任务，按提交顺序排队。

### Q6：离线可以记账吗？
A：可以。App 端支持离线记账，联网后会自动同步。

### Q7：验证码多久有效？
A：5 分钟。同邮箱同类型 60 秒内不可重复发送。

### Q8：如何切换账本？
A：在首页顶部点击账本名称即可切换，或进入"账本管理"选择。

### Q9：数据安全吗？
A：所有接口默认加密传输（RSA+AES），密码使用 BCrypt 加密存储，token 24 小时自动过期。

### Q10：如何反馈问题？
A：请联系管理员或在问题反馈渠道提交。

## 7. 使用技巧

### 7.1 智能分类
- 在备注中包含关键词（如"星巴克"、"美团"、"滴滴"），系统会自动推荐分类
- 可在记账时点击"智能分类"按钮手动触发

### 7.2 标签组合
- 为交易添加多个标签，便于后续筛选
- 例如：给"出差"相关的交易都打上"出差"标签

### 7.3 预算控制
- 为高频支出分类设置预算（如餐饮、日用品）
- 阈值建议设为 80%，提前预警避免超支

### 7.4 定期导出
- 每月导出一次账单，作为备份
- 邮件接收，方便归档

### 7.5 共享账本
- 家庭开支可创建共享账本
- 夫妻双方各自记账，数据实时共享
- 互相可见但不可修改对方记录
