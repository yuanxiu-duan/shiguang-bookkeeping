# 流水"编辑"与"添加人"功能验证清单

> 适用范围：jz-server (Java/Spring Boot 3 + JDK 21)、jz-web (Vue 3 + Element Plus)、jz-app (uniapp + Vue 2)

## 一、改动摘要

| 模块 | 文件 | 改动内容 |

| 后端 | `jz-server/src/main/java/com/moneykeeper/entity/Transaction.java` | 已具备 `@Transient String createdBy` 字段 |

## 二、接口验证（PowerShell + curl 示例）

> 假设：后端地址 `http://localhost:8070`，已通过 `/api/auth/login` 取得 `TOKEN`，且 `BOOK_ID=1`，待编辑 `TXN_ID=10`。

### 1. 列表返回应包含 `createdBy`

```powershell
curl.exe -H "Authorization: Bearer $env:TOKEN" `
  "http://localhost:8070/api/transactions/all?accountBookId=1&page=0&size=5"
```

预期：`data.content[*].createdBy` 不为空，为创建该流水的用户名。

### 2. 修改流水接口

```powershell
curl.exe -X PUT -H "Authorization: Bearer $env:TOKEN" -H "Content-Type: application/json" `
  "http://localhost:8070/api/transactions/10?accountBookId=1" `
  -d '{"amount":99.99,"type":"EXPENSE","categoryId":1,"transactionDate":"2026-06-10","note":"修改测试","tagIds":[]}'
```

预期：
- HTTP 200，`code = 200`；
- 返回数据 `userId` 与修改前一致（添加人未被覆盖）；
- 返回数据 `createdBy` 仍是原始添加人。

### 3. 权限校验（非创建者且非账本所有者）

切换至另一个普通成员的 TOKEN，再次执行步骤 2，预期返回错误："无权限修改此记录，只有记录创建者或账本所有者可以修改"。

## 三、Vue Web (jz-web) 页面验证

访问：`http://localhost:5173/`，登录后进入【账单流水】

1. ✅ 列表中每行新增"**添加人**"列，显示为创建该笔流水的用户名（灰色 tag）。
2. ✅ 操作列同时显示【修改】与【删除】两个按钮。
3. ✅ 点击【修改】：
   - 非本人/非账本所有者：toast 提示"只有记录创建者或账本所有者可以修改此记录"；
   - 本人或账本所有者：弹出对话框，包含【类型 / 金额 / 分类 / 标签 / 日期 / 备注】所有字段；
   - "添加人"以禁用 tag 展示，并提示"添加人不可修改"；
   - 切换类型，分类下拉自动刷新对应类型的分类列表；
4. ✅ 修改保存成功后：toast 显示"修改成功"，列表与汇总数据自动刷新。
5. ✅ 删除前也进行权限校验，无权限时弹出 warning 而不进入确认框。

## 四、uniapp (jz-app) 页面验证

H5 启动：`npm run dev:h5`（默认在 `http://localhost:5174` 或终端打印的地址），登录进入首页。

1. ✅ 流水列表每行右下角显示添加人（紫色小 tag，即 `item-creator` 样式）。
2. ✅ 长按或点击某条流水弹出 ActionSheet（要求是本人或账本所有者）。
3. ✅ 选择"编辑"，弹出新版编辑弹窗，包含：
   - **类型**（支出/收入 切换 → 分类列表会切换）
   - **金额**（数字键盘）
   - **分类**（picker 选择器，绑定后端 `categoryApi.getCategoriesByType`）
   - **日期**（date picker）
   - **备注**（文本）
   - **添加人**（只读 tag + "添加人不可修改"提示）
4. ✅ 保存成功后 toast "修改成功"，列表与本月汇总自动刷新。
5. ✅ 非本人且非账本所有者点击该流水，不会出现 ActionSheet（与原逻辑一致）。

## 五、回归用例

| 编号 | 用例 | 预期 |
| ---- | ---- | ---- |
| R1 | 新建流水后查看列表 | 添加人 = 当前登录用户 |
| R2 | A 创建流水后，A 修改 | 成功，添加人不变 |
| R3 | 账本所有者 B 修改 A 创建的流水 | 成功，添加人仍为 A |
| R4 | 普通成员 C 修改 A 创建的流水 | 失败，提示无权限 |
| R5 | 修改时切换类型 | 分类下拉刷新为新类型分类 |
| R6 | 修改后查看月度汇总 | 收/支金额按新值更新 |

## 六、注意事项

- Windows 端启动命令：
  - 后端：`mvn -s <你的 Maven settings.xml 路径> spring-boot:run`（cwd: `jz-server`）
  - Vue Web：`npm run dev`（cwd: `jz-web`）
  - uniapp H5：`npm run dev:h5`（cwd: `jz-app`）
- 数据库无需变更：`transactions.user_id` 即为添加人字段。
- 已有 `enrichWithCreatedBy` 在 `getTransactions` / `getAllTransactionsPaged` / `createTransaction` / `updateTransaction` 中调用，确保所有页面均能拿到添加人。
