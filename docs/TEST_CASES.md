## 1. 测试概述

### 1.1 测试范围
- **功能测试**：覆盖所有业务功能模块
- **接口测试**：覆盖 72 个 API 接口
- **异常测试**：边界值、异常输入、权限校验
- **兼容性测试**：多端、多浏览器、多分辨率
- **安全测试**：加密、认证、越权

### 1.2 测试环境

| 前端 App | uni-app H5 / Android / iOS |

| 测试工具 | Postman / JUnit / 手工测试 |
