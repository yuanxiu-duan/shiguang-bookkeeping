## 1. 项目概述

### 1.1 产品定位
拾光账本是一款面向个人与家庭的轻量级多端记账应用，支持 **iOS / Android / H5 / 微信小程序 / Web 管理端** 五端覆盖。核心价值在于"随手记、随时查、多人共账、智能分类"，帮助用户清晰掌握日常收支、合理规划预算、养成理财习惯。

### 1.2 商业目标
- 解决传统记账软件"操作繁琐、单机孤岛、数据难迁移"的痛点
- 支持家庭/团队共享账本，多人协同记账
- 提供完整的预算预警与统计分析能力
- 通过 Web 管理端满足桌面端深度操作场景

### 1.3 适用对象
| 角色 | 描述 | 主要场景 |
|------|------|----------|
| 普通用户（USER） | 个人记账用户 | 日常收支记录、预算管理、统计分析 |
| 家庭/团队成员 | 共享账本成员 | 多人协同记账、邀请管理 |
| 管理员（ADMIN） | 系统运营人员 | OSS 配置、APP 发布管理 |

## 2. 术语表

| 术语 | 含义 |
|------|------|
| 账本（AccountBook） | 用户记账的容器，可个人可共享 |
| 交易（Transaction） | 一笔收支记录，类型为 EXPENSE/INCOME |
| 分类（Category） | 交易归类，分支出/收入两类 |
| 标签（Tag） | 交易的辅助标记，可多对多 |
| 预算（Budget） | 月度分类预算限额 |
| 预算预警（BudgetAlert） | 预算超阈值时生成的提醒 |
| 共享账本成员 | 被邀请加入共享账本的用户，角色 OWNER/MEMBER |
| OSS | 对象存储服务，用于 APP 升级包存储 |
| CryptoFilter | 请求/响应加解密过滤器 |

## 3. 用户角色与权限

### 3.1 角色定义
| 角色 | 标识 | 权限范围 |
|------|------|----------|
| 游客 | GUEST | 注册、登录、找回密码、APP 更新检查、下载导入模板 |
| 普通用户 | ROLE_USER | 个人记账全功能、共享账本管理、个人信息维护 |
| 管理员 | ROLE_ADMIN | 包含普通用户全部权限 + OSS 配置 + APP 发布管理 |

### 3.2 账本成员角色
| 角色 | 标识 | 权限 |
|------|------|------|
| 所有者 | OWNER | 账本全部操作、邀请/移除成员、删除账本 |
| 成员 | MEMBER | 在账本内记账、查看、编辑自己创建的记录 |

### 3.3 数据权限规则
- 交易记录：仅 **创建者** 或 **账本 OWNER** 可编辑/删除
- 预算/标签/分类：按用户维度隔离，账本内共享
- 共享账本：成员可见账本内全部交易，但不可操作他人记录

### 5.3 关键交互说明

#### 5.3.1 登录流程
1. 用户进入登录页，默认密码登录模式
2. 可切换至验证码登录模式（输入邮箱→发送验证码→登录）
3. 登录成功后 token 存入本地存储，跳转记账首页
4. token 失效（401）自动跳转登录页

#### 5.3.2 记一笔流程
1. 点击首页"+"或底部"记账"入口
2. 选择类型（支出/收入）→ 选择分类 → 输入金额
3. 可选填备注、标签、日期、账本
4. 备注输入后可点击"智能分类"按钮自动推荐分类
5. 保存后返回首页，列表实时刷新

#### 5.3.3 共享账本流程
1. 创建账本（首个自动设为默认）
2. 进入账本详情 → 邀请成员（输入用户名）
3. 被邀请人在"账本管理"看到待处理邀请
4. 接受邀请后成为该账本 MEMBER
5. 成员可在该账本内记账，但仅能编辑/删除自己的记录

#### 5.3.4 预算预警流程
1. 创建月度分类预算（如：餐饮 2000 元，阈值 80%）
2. 用户记账时累计该分类支出
3. 支出达到 1600 元（2000×80%）时生成预警
4. 首页 TabBar"我的"显示未读预警红点
5. 进入预警页面查看详情，标记已读

#### 5.3.5 数据导出流程
1. 进入"导出数据"页面
2. 选择时间范围 + 目标邮箱
3. 提交导出任务（POST /api/transactions/export-tasks）
4. 服务端定时串行处理（每 60 秒一次，每次 1 个任务）
5. 生成 Excel，文件 > 10MB 自动压缩 zip
6. 作为邮件附件发送到用户邮箱
7. 用户可在"导出数据"页面查看最近任务状态

#### 5.3.6 APP 升级流程
1. App 启动后延迟 3 秒静默检查更新
2. 调用 /api/admin/app-releases/check-update 传入当前版本
3. 服务端优先比较 versionName 语义版本，versionCode 辅助
4. 有新版本时：
   - 强制更新：弹出不可取消对话框
   - 可选更新：弹出可取消对话框
5. Android：下载 APK → 进度条 → 调用系统安装器
6. iOS：跳转浏览器下载链接

## 6. 非功能性需求

### 6.1 性能需求
| 指标 | 要求 |
|------|------|
| 接口响应时间 | P95 < 500ms（除导出/导入） |
| 列表分页 | 默认 20 条/页，支持自定义 |
| 文件上传限制 | 单文件 500MB |
| 异步任务处理 | 每 60 秒处理 1 个任务 |
| 大文件压缩阈值 | > 10MB 自动 zip |

### 6.2 安全需求
| 项目 | 实现方式 |
|------|----------|
| 密码存储 | BCrypt 加盐哈希 |
| 身份认证 | JWT 无状态，24 小时有效期 |
| 接口加密 | RSA + AES 混合加密（CryptoFilter） |
| 跨域 | CORS 白名单配置 |
| SQL 注入 | JPA 参数化查询 |
| 输入校验 | jakarta.validation 注解 |
| 密钥管理 | 配置文件，禁止硬编码 |

### 6.3 兼容性需求
| 端 | 要求 |
|----|------|
| Android | 5.0+（API 21+） |
| iOS | 10.0+ |
| H5 浏览器 | Chrome 80+ / Safari 13+ / Edge 80+ |
| 微信小程序 | 基础库 2.10+ |
| Web 管理端 | Chrome 90+ / Edge 90+ / Firefox 88+ |

### 6.4 可用性需求
- 离线支持：uni-app 端支持离线记账，联网后自动同步
- 错误提示：所有操作失败有明确中文提示
- 加载状态：列表加载有 loading 动画
- 表单校验：实时校验 + 提交校验双重保障

## 7. 数据流与业务规则

### 7.1 关键业务规则
1. **默认账本**：用户注册时自动创建名为"默认账本"的账本，is_default=true
2. **默认分类**：注册时自动初始化 13 个默认分类（8 支出 + 5 收入）
3. **验证码有效期**：5 分钟，同邮箱同类型 60 秒内不可重复发送
4. **预算唯一性**：同用户同月同分类同账本只能有一个预算
5. **预警去重**：同用户同分类同月同日只生成一条预警
6. **交易权限**：仅创建者或账本 OWNER 可编辑/删除
7. **共享账本成员上限**：暂未限制（可后续扩展）
8. **导出任务保留**：仅返回最近若干条，历史任务不展示

### 7.2 数据加密流程
```
前端                                      后端
 │                                         │
 │  1. GET /api/auth/public-key            │
 │ ───────────────────────────────────────>│
 │  2. 返回 RSA 公钥                        │
 │ <───────────────────────────────────────│
 │                                         │
 │  3. 生成随机 AES 密钥                    │
 │  4. RSA 加密 AES 密钥 → encKey           │
 │  5. AES 加密请求体 → encData             │
 │  6. POST { encKey, encData }            │
 │ ───────────────────────────────────────>│
 │                          7. RSA 解密得到 AES 密钥
 │                          8. AES 解密得到原始 body
 │                          9. 业务处理
 │                         10. AES 加密响应 → encData
 │  11. 返回 { encData }                    │
 │ <───────────────────────────────────────│
 │ 12. AES 解密得到原始响应                  │
```
